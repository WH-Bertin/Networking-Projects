# Networking Projects

Welcome to the *Networking Projects* repository! This repository serves as a centralized collection of various networking labs, configurations, and topology designs, focusing on fundamental and advanced networking concepts.

##  Current Projects & Labs

### 1. Network Basic Configuration & Static Routing
Located in the network Basic configuration directory, this lab focuses on setting up foundational network environments and establishing connectivity using static paths.

*   *Objective:* Understand basic device initialization and manual route configuration.
*   *Key Concepts Covered:*
    *   Host name assignment and interface IP configuration.
    *   Configuring IPv4/IPv6 static routes.
    *   Setting up default routes for internet/gateway simulation.
    *   Verifying connectivity using ping and traceroute/tracert.

##  How to Use This Repository

### Prerequisites
To run or view the topology configurations, ensure you have the appropriate network simulator installed:
*   [Cisco Packet Tracer](https://netacad.com) (if using .pkt files)
*   [GNS3](https://gns3.com) or [EVE-NG](https://eve-ng.net) (if using complex emulated topologies)

### Steps to Run a Lab
1.  *Clone the repository:*
    bash
    git clone https://github.com
    
2.  Navigate to the specific lab directory (e.g., network Basic configuration).
3.  Open the topology file or apply the provided text-based startup configurations directly onto your virtual devices.
